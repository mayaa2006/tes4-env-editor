    How this works

    1. Add clips on the right: the word, a name for this take, and the file. Add as many takes of a word as you like.
    2. Click Find words in all lines once. It listens to each line and notes where every word is.
    3. Open a line. Words that get replaced by default are highlighted. For each one, pick a take (or leave it on Auto), nudge the edges if the cut sounds off, then press ▶ With replacements.
    4. Press Save line as .mp3. The file goes into the output folder with the same name and folder layout as the game expects.

    The mouth movement (.lip files) can't be made here; use the Construction Set for that.
